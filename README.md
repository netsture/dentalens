# DentSaas Frontend (Demo)

ERP-style console layout + DentSaas pages (appointment book, billing, settings).

## Run

```bash
cd aa
npm install
npm run dev
```

Open http://localhost:5174

## Demo login

| Role | Email | Password |
|------|-------|----------|
| Administrator | `admin@gmail.com` | `admin@123` |
