# Build Dynamic Patient Forms Management & PDF Printing System

## Existing Technology Stack

- Frontend: React + Vite
- Backend: Python + FastAPI
- Database: MySQL
- PDF Generation: Python ReportLab + pypdf
- Barcode: Code 128
- Existing application: Dental Practice Management System

IMPORTANT:
Implement this functionality inside the existing application. First inspect the existing project structure, authentication, database schema, patient tables, office tables, API conventions, UI components and permissions. Reuse existing components and database connections. Do not create a separate application or duplicate existing patient records.

## 1. Main Objective

Develop a complete Dynamic Patient Forms Management System.

Administrators must be able to manage patient form categories, upload existing PDF templates, configure dynamic patient information, barcode positions, headers, footers and page layouts.

Regular users must be able to select a patient, select a form category, select one or multiple forms, generate the PDF, preview it, print it and download it.

The generated PDF must reproduce the uploaded original PDF as accurately as possible, including page dimensions, layout, fonts, tables, lines, spacing, barcode positions, headers and footers.

Use the attached original 4-page PDF as the reference template.

Do not redesign or modernize the original PDF.

## 6. Barcode Generation

Use Code 128 barcode generation.

Barcode values must be configurable and generated according to the existing application barcode rules.

For the uploaded reference PDF, the sample values are:

Page 1: 00015300047886000422001
Page 2: 00015300047886000423001
Page 3: 00015300047886000423002
Page 4: 00015300047886000424001

IMPORTANT:
Preserve leading zeros.

Do not convert barcode values to integers.

Store barcode values as VARCHAR.

Support:
- Barcode at top-right.
- Barcode at bottom.
- Page-specific barcode values.
- Configurable barcode width and height.
- Configurable barcode X/Y position.
- Human-readable barcode text.
- Barcode preview.

Do not hardcode the sample barcode values in production. Implement a configurable barcode-generation service and connect it to the existing barcode numbering rules.

## 8. PDF Generation Backend

Implement a reusable Python PDF generation service using:

- ReportLab
- pypdf
- python-barcode
- Pillow

Generation workflow:

1. Receive patient ID, form IDs and office ID.
2. Validate user authentication and office permissions.
3. Fetch patient details.
4. Fetch office details.
5. Fetch doctor/staff information.
6. Fetch published form templates.
7. Load original PDF templates.
8. Generate page-specific barcode values.
9. Generate barcode images.
10. Overlay dynamic patient information.
11. Merge generated overlays with original PDF pages.
12. Preserve original PDF dimensions and layout.
13. Add page numbers where configured.
14. Generate the final PDF.
15. Save the generated PDF securely.
16. Store the submission and print-history information.
17. Return a secure download/preview URL.

Support multi-page forms and multiple selected forms in one PDF.

Do not load unnecessarily large files into memory.

Use temporary files or controlled file streams for PDF processing.
